# 📊 Flipkart Sales Performance Analysis Dashboard

## 📌 Project Overview
The **Flipkart Sales Performance Analysis Dashboard** is an interactive Microsoft Excel project designed to analyze and visualize Flipkart sales data. This dashboard provides meaningful business insights through KPIs, Pivot Tables, Pivot Charts, Slicers, and dynamic visualizations.

The objective of this project is to help businesses monitor sales performance, identify profitable products, compare regional sales, and analyze customer payment preferences for better decision-making.

---

## 🎯 Objectives

- Analyze overall sales performance
- Track Total Revenue and Total Profit
- Identify the highest revenue-generating category
- Compare sales across different regions
- Analyze payment mode preferences
- Identify the most profitable products
- Build an interactive dashboard using Excel
